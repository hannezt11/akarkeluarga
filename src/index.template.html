Set gabungan

Satu set = beberapa akar yang tampil menyatu. Contoh: set 1 berisi Akar A + B, set 2 berisi Akar C + D. Saat kamu membuka akar mana pun, set yang memuat akar itu otomatis tampil.

Peran saya di tiap akar

Pilih siapa Anda di setiap akar. Orang dengan peran yang sama di akar berbeda otomatis dianggap satu orang, jadi akar-akar itu tersambung. Cukup isi yang ada di akar tersebut.
