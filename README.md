# Akar Keluarga (Capacitor)

Kode sumber di `src/` (css/, js/, index.template.html). `www/index.html` dibuat otomatis oleh
`node build.js` (CI juga menjalankannya). Jangan edit `www/index.html` langsung.
File `src/js/*.js` adalah satu fungsi yang sama, urutan nomor jangan diubah.
Alur: edit `src/`, jalankan `node build.js`, push ke `main`. Folder `android/` dibuat oleh CI.
